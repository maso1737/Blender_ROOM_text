色は AE の色そのまま、明るさは AE の明度そのままになります。レインボーを流すのも、特定の電球だけ赤にするのも、AE で描けば全部そのまま出ます。

拡張としてはこれが一番強い方法です。迷ったらこれを選んでください。
彩度の高い色（特に青）が光らないことがあります。直し方は2つの合わせ技：

②だけ極端に下げると消灯しているはずの電球までうっすら光るので、①②のバランスで探してください。

真っ黒になったら

この5つで、ほぼ全部の「光らない」が直ります。上から順に確認してください。

1 ／ Attribute の Type が Geometry のままになっていませんか

いちばん多い原因です。Instancer に変えてください。球そのものではなく、球を配っている格子が値を持っています。

2 ／ Realize Instances が入っていませんか

これが入った瞬間、Instancer からの受け渡しが切れて真っ黒になります。しかも数千個で極端に重くなります。入れないのが正解です。

3 ／ Store Named Attribute の Geometry 入出力、本線に繋がってますか

いちばん見落としやすい原因です。値（計算結果）だけ繋いでも属性は書き込まれません。数珠つなぎの図のとおり、緑のジオメトリ線が Store を通り抜けているか確認してください。
合わせて：Instance on Points より 前 にあるか／Domain が Point か／名前がマテリアル側と 1文字違わず 同じか（大文字小文字も区別）。

4 ／ Set Material をつなぎましたか

ジオメトリノードで作った形には、オブジェクトのマテリアルが自動では乗りません。Set Material ノードで明示的に指定します。

5 ／ Attribute ノードを複製した時、Name欄を書き換え忘れてませんか

属性が3本になると Shift+D で複製しがちです。Name 欄を変え忘れたまま Image Texture や Color Ramp に繋いでいないか、マテリアルの Attribute ノードを1個ずつクリックして確認してください。

結局どれが速いか

01〜05 は「仕組みの理解」です。模様を1つ作るたびにノードを組み替えるので、映像の尺合わせには向きません。

実制作では 06 を主役に。仕掛けを1本に固定して、模様の設計とタイミングは全部 AE 側でやる。これが一番速く、一番やり直しが効きます。01〜05 は「揺らぎの足し算」として重ねると、機械的になりすぎません。
